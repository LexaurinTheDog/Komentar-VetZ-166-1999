# Komentář k zákonu č. 166/1999 Sb., o veterinární péči (veterinární zákon)

Odborný komentář k **zákonu č. 166/1999 Sb., o veterinární péči (veterinární zákon)** — předpisu ochrany zdraví zvířat a bezpečnosti živočišných produktů: povinnosti chovatelů, nákazy a mimořádná veterinární opatření, veterinární hygiena produktů, Státní veterinární správa, soukromí veterinární lékaři, asanace a náhradový systém.

Konsolidované znění: dokument e-Sbírky `SB-1999-00166_2026-01-01`.
